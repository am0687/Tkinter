# Contact Book Managing System

A lightweight, desktop-based graphical user interface (GUI) application to digitally manage and store contact information. Built using Python's standard `tkinter` library for the frontend and `sqlite3` for persistent backend database storage.

## Features (CRUD)
* **Create:** Add new contacts with automated ID generation.
* **Read:** View all saved contacts in a structured table and search by name.
* **Update:** Select any existing contact to modify their details.
* **Delete:** Remove contacts from the database.
* **Validation:** Built-in checks for empty fields, 10-digit phone numbers, and valid email formatting.

## Prerequisites
* **Python 3.x** installed on your system.
* No external libraries (like `pip install`) are required! Both `tkinter` and `sqlite3` are part of the standard Python library.
